# Phase 4 report — audio, dialogue sync, Thai subtitles, music & SFX

Status: **pipeline built and tested with free mock voices.** No ElevenLabs
credits have been used. Real voices need the owner's voice choices and
approval of a paid generation run (see "Next step").

Details: `docs/audio-pipeline.md`.

## What was built

| Area | Capability |
|---|---|
| Voice pipeline | `prepare-episode-audio.ts`: imported → voice cache → paid ElevenLabs (guarded) → mock; duration, loudness envelope, character alignment; ledger of billed characters |
| Paid-call guard | key + `ELEVENLABS_ALLOW_PAID_CALLS=true` + `--confirm-paid` + character budget (checked before any call) + voice IDs; `--dry-run` shows billable characters; renders can never make paid calls |
| Cache | every line cached by text/voice/model/settings; re-renders and mock mode reuse paid voices for free; single-line `--regenerate` |
| Dialogue sync | lines placed on real audio (pushed, never overlapped or shortened), scenes grow to fit; `camera.shots[].onLine` cuts on speech |
| Lip sync | mouth from the voice's loudness envelope, rounded vowels from alignment, automatic subtle talking head motion |
| TTS text | written text for subtitles, spoken text for the voice (kW → กิโลวัตต์ etc.; `speak` override) |
| Thai subtitles | word-boundary, balanced, glossary-protected wrapping; 26 visual chars × 2 lines; safe area; legend-aware; `.th.srt` exported beside every render |
| Music / SFX | original procedurally synthesised library (music bed, room tone, 5 SFX); scene and episode-wide cues; ducking under speech (default −12 dB, 8-frame ramps); fades |

Tests: 134 passing (25 new in `tests/audio.test.ts`: wrapping, timing,
ducking, lip sync, SRT, cache keys, mock/cache/paid modes with a fake TTS,
request format, key never in URLs or errors).

## Dialogue test (mock voices)

`src/episodes/phase4-dialogue-test.episode.json` (generated by
`scripts/review/build-phase4-dialogue-test.mjs`): Ton and Sunny talk in the
living room, then Sunny explains the yellow and cyan lines in the cutaway
house. 6 lines, music bed with ducking, room tone, whoosh + pop SFX, Thai
subtitles, lip sync, speech-anchored camera cuts. 25.5 s after timing.

Mock voices are a quiet synthetic hum with syllable rhythm — they test
timing, ducking, subtitles and lip sync, and must never be published.
