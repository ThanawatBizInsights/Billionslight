# Official Billionslight branding

The official logo PNGs (`billionslight-logo-stacked.png`,
`billionslight-logo-horizontal.png`) are owner-supplied and **git-ignored**
(public repository). Copy them here from the Drive "Logo" folder (via the
Google Drive connector) before rendering episodes with a `logo` overlay.

Never modify proportions, typography or colours; never remove the tagline.
Brand colours: orange #FF5E1F, blue #1B28CE (designer brand sheet).
